# Dynamic AI Portfolio

A modern, full-stack portfolio built with Next.js, Node.js/Express, MongoDB, and OpenAI.

## Project Structure
- `/frontend` - Next.js application
- `/backend` - Express API
- `/docs` - Project documentation and architecture logs
- `/.vscode` - Editor configuration for automatic formatting

## Setup
When opening this project in VS Code, accept the prompt to install the recommended extensions to ensure formatting and linting work correctly.
